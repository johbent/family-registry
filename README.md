# دليل العائلات – واجهة Cloudflare D1

واجهة عربية RTL للبحث في سجلات السكان وعرض الأب والأم والأخوة والأبناء وشجرة مبسطة. البحث المنشور يقرأ من Cloudflare D1، مع استثناء المحافظات ذات الرموز 71، 72، 73، 74، 75، 76، 77، 78، و88 من نتائج البحث دون حذفها من قاعدة البيانات.

## ملاحظة مهمة عن الأرشيف المرفق

الأرشيف `شجرة العائلات.rar` يحتوي على **Microsoft Access Jet MDB** باسم `sokan_2005.mdb` (حجمه غير مضغوط 583,708,672 بايت) وليس Excel. يجب تصدير جداول/استعلامات البيانات الفعلية من Access ثم فحص الحقول وعلاقاتها قبل اعتبار النسخة مكافئة للبرنامج الأصلي. هذه الواجهة الأولية لا تحاكي تلقائيًا استعلامات أو نماذج أو تقارير Access الأصلية.

## تجربة محلية

افتح `index.html` بمتصفح حديث. يفضل تشغيل خادم HTTP محلي بواسطة `python -m http.server 8000` ثم زيارة `http://localhost:8000`. يتطلب IndexedDB وضع HTTP/HTTPS آمنًا أو localhost.

## تجهيز بيانات CSV من Microsoft Access

1. افتح نسخة **احتياطية** من `sokan_2005.mdb` ببرنامج Microsoft Access (يفضل بيئة Windows متوافقة مع القاعدة القديمة).
2. افحص أسماء الجداول والاستعلامات لتحديد جدول الأشخاص ومفاتيح الربط. لا تفترض أن عمود اسم الأب يشير إلى الشخص نفسه دون مفتاح فريد.
3. من `External Data` > `Text File` أو `Export` صدّر استعلام الأشخاص إلى CSV مع رؤوس الأعمدة. يفضل UTF-8؛ يمكن للموقع القراءة بترميز Arabic Windows-1256.
4. حقول الربط المطلوبة: رقم ثابت فريد لكل شخص، الاسم، العائلة، ومعرف الأب ومعرف الأم إن كانا موجودين. إن لم تتوفر أرقام الأب/الأم، اعرض الأسماء النصية فقط ولا تختلق صلات قرابة.
5. افتح الموقع، اضغط «استيراد ملف CSV»، حدد الترميز، «قراءة الأعمدة»، اربط الحقول ثم «استيراد البيانات وحفظها».
6. استعمل «تصدير نسخة JSON» لحفظ البيانات المنقولة خارج المتصفح، و«استعادة JSON» على الأجهزة الأخرى. **JSON الناتج يحتوي بيانات شخصية حساسة فلا تنشره**.

## نشر Cloudflare Pages مع GitHub

1. أنشئ مستودع GitHub خاصًا (Private) وارفع **فقط** ملفات الواجهة `index.html`, `app.js`, `_headers`, `README.md`, `.gitignore`.
2. في Cloudflare: `Workers & Pages` → `Create` → `Pages` → الاتصال بمستودع GitHub.
3. استخدم إعداد نشر مشروع Static: Build command فارغ، وOutput directory هو `/` (أو اجعلها `.` إذا طلبت اللوحة مجلدًا).
4. بعد النشر تفتح الواجهة عبر `pages.dev`؛ يلزم استيراد البيانات في كل متصفح على حدة أو استعادة نسخة JSON.
5. **مستودع GitHub الخاص لا يجعل رابط Pages خاصًا**؛ إذا أردت منع الجمهور من فتح الواجهة اضبط Cloudflare Access على النطاق، إضافة إلى عدم وضع أي بيانات شخصية في ملفات الموقع.

## قاعدة البيانات المنشورة

يُستورد جدول `Sgaza` إلى جدول `sgaza` في D1، وتُستورد جداول `المحافظات` و`المناطق` لاستخدامها في المطابقة الجغرافية. جدول `قائمة الموظفين` لا يُنشر تلقائيًا لأنه يحتوي حقولًا شخصية إضافية وليس مطلوبًا لبحث العائلات. تُحفظ نسخة Access الأصلية خارج GitHub.

## حدود معالجة العلاقات

الأخوة يحسبون من **معرف الأب أو معرف الأم** المتطابق؛ أبناء الشخص من وجود معرفه في حقلي الأب/الأم. لا يستنتج الموقع النسب من مجرد تشابه اسم العائلة. البحث عن أب/أم بالاسم النصي يعرض سجلًا مرتبطًا فقط عند التطابق الفريد للاسم الكامل. البيانات القديمة قد تتطلب تنظيفًا وتدقيقًا بشريًا.
